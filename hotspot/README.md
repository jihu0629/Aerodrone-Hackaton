# 쓰레기 밀집지역 검증 (하와이 2015 항공조사)

질문: 지형(해안이 바라보는 방향)만으로 쓰레기가 몰리는 구간을 미리 고를 수
있는가? → 위성지도로 드론 비행 우선순위를 정한다는 주장의 근거가 되는지 확인.

데이터: Zenodo 8381113 (CC-BY 4.0), 2015년 하와이 주 해안 항공촬영 2 cm/px,
칩 1,587장 / 라벨 10,703개. `data/`에 내려받음 (git 제외).

```bash
python3 windward_test.py
```

## 결과

| 확인한 것 | 결과 |
|---|---|
| 1 km 격자 집중도 | 쓰레기 있는 칸 434개 중 **상위 10%가 라벨의 75%**, 상위 20%가 87% |
| 섬별 방향 쏠림 | 대부분 섬에서 8방위 중 1~2개 방향에 **66~95%** 집중 (몰로카이 NW 78%, 카호올라웨 NE+E 95%, 니이하우 NE+S 92%). 예외는 오아후(고르게 분산, 쓰레기 총량도 최저) |
| 무역풍(북동) 정면 해안 | 전체로는 기대값(25%)의 **1.6배(39.7%)**. 그러나 섬마다 다름 — 니이하우·카우아이·카호올라웨·라나이는 맞고, 몰로카이·마우이는 기대보다 낮음 |

## 해석

1. **밀집은 확실히 존재한다.** 상위 10% 칸에 75%가 몰려 있다. 쓰레기 없는
   해안 칸까지 포함하면 이 비율은 더 올라간다(빈 칸은 분모에만 추가되므로).
2. **"바람 받는 쪽" 규칙 하나로는 부족하다.** 하와이섬은 남쪽(S 44%)에 몰려
   있는데, 해류로 쓰레기가 쌓이는 것으로 유명한 카밀로 해변 쪽이다. 즉 바람만이
   아니라 해류·국지 지형이 같이 작용한다 — 문헌의 GIS 예측 모델이 여러 변수를
   쓰는 이유와 일치.
3. 그래서 우선순위는 "풍향 규칙"이 아니라 **한 번의 광역 조사(또는 과거 이력)로
   밀집 칸을 찾고, 다음부터는 그 칸 위주로 정밀 비행**하는 방식이 현실적이다.
   이게 맞으려면 밀집 칸이 시간이 지나도 유지돼야 하는데, 이 데이터는 단일
   시점이라 그건 검증하지 못했다 → NOAA MDMAP 반복조사 데이터로 확인 필요.

## 시간 반복성 — NOAA MDMAP

```bash
python3 mdmap_persistence.py   # 공개 API에서 지점·조사·쓰레기 수를 받아 data/mdmap/에 캐시
python3 plot_results.py        # hotspot_results.png
```

같은 해안 구간(보통 100 m)을 반복 조사하고 매번 전부 치우는 방식이라, 각 조사
값은 "치운 뒤 다시 쌓인 양"이다. 조사 8회 이상·2개 연도 이상인 134곳(지점당
중앙값 15회)을 기간 앞/뒤 절반으로 나눠 비교했다.

| 확인한 것 | 결과 |
|---|---|
| 앞/뒤 기간 밀도 순위상관 | **0.88** |
| 앞 기간 상위 20%(27곳)가 뒤 기간에도 상위 20% | **74%** (우연이면 20%) |
| 앞 기간 상위 20%만 다시 갔을 때 | 뒤 기간 쓰레기의 **56%** 커버 |

하와이 4곳 중 1위는 카밀로 포인트 — 2015 항공조사에서 하와이섬 남쪽에 몰려
있던 바로 그 해류 집적지다. 두 데이터가 같은 핫스팟을 가리킨다.

주의: MDMAP 지점은 자원봉사자가 고른 곳이라("여기 늘 쓰레기가 보여서" 같은
이유가 많음) 무작위 표본이 아니다. 또 지점 간 차이(도시/외딴 해변)가 커서 순위
상관이 높게 나오기 쉽다 — 하지만 그 "지점 고유의 성질"이 유지된다는 것 자체가
우리가 확인하려던 것이다.

## 한계

- 칩은 쓰레기가 있는 곳만 담은 학습용 표본이다. 칩 수의 섬별 비율(니이하우 36%,
  오아후 5%)은 원 조사 전수 집계(38%, 5%)와 비슷하지만, 라벨 수 비율은 니이하우가
  53%로 더 높다.
- 해안 방향은 "섬 중심 → 칩" 방위각으로 근사했다. 몰로카이·마우이처럼 길쭉하거나
  두 덩어리인 섬에서는 이 근사가 부정확하다.
