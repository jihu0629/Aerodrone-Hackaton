# 결과 리포트 시각화 (report.html)

파이프라인이 결과를 낼 때마다 `report.html` 한 장을 만든다. 인터넷·추가 설치 없이 브라우저로 열린다.
미리보기(합성 장면, 3D 모드): https://claude.ai/artifact/2vsp1eFnjP7yy6NtsBqncT

**실제 해변 사진 리포트 (2D 모드)**: `python scripts/16_photo_demo.py` — Andriolo 2024 그림 크롭 4장(CC BY). 그림 3c 는 논문 저자의 빨간 윤곽을 라벨로, 그림 1d 는 색 기반 베이스라인(오검출 포함). DSM 이 없으므로 면적·개수 기반(W2/W3)으로 추정하고 리포트가 'DSM 없음' 을 표시한다. 학습된 모델이 있으면 `--weights best.pt`.

## 구성
1. 추정 총 무게 (큰 숫자) + 최소–최대 범위
2. 타일: 검출 개수, 총 부피, 마대·톤백·트럭, 작업 인·시간, 23 kg 초과, (실측 있으면) 오차
3. 검출 오버레이: 정사영상 위 종류별 색 윤곽, 마우스 올리면 종류·무게 범위·부피·면적·높이·계산 방식
4. **원본 프레임 검출**: 드론 영상 프레임에 분할 모델을 돌린 결과 (폴리곤 + 종류·신뢰도 라벨, 최대 6장). `scripts/13 --frames 폴더`
5. **추정 근거 (물체별)**: 물체마다 카드 — 정사영상 조각 + 분할 폴리곤 / DSM 높이 조각 / 면적·최대 높이·부피·무게 / 계산식 "V = Σ(DSM−바닥)·GSD² = … → m = V × ρ(최소/대표/최대) = …". 무게 순 12개, 나머지는 펼치기
6. 종류별 무게 막대 (대표값 + 범위 선)
7. 격자 무게 히트맵 (10 m, 우선 수거 순위 배지 1–5)
8. 기존 방식 비교: 우리 3D vs W2·W3·W3′ (실측 있으면 세로선)
9. 수거 계획 표, 무거운 물체 목록, 차량 경로
10. 전체 물체 표 (접힘)
11. 가정과 한계

## 설계 원칙
- 무게(크기)는 파란색 한 가지의 진하기, 종류는 고정 순서 8색 (색맹 검증 통과 팔레트)
- 모든 차트에 "표로 보기" 제공 (색 없이도 읽힘)
- 다크 모드·휴대폰 폭 대응
- 발표 화면은 브라우저에서 캡처

## 사진 리포트를 함께 출력
`--photos 폴더` 를 주면 같은 출력 폴더에 `report_photos.html` 이 함께 생기고 두 리포트가 서로 링크된다.
사진 GSD 는 `widths.json`(파일명→폭 m) → `--photo-width` → DJI 사진 EXIF/XMP 고도 + Mini 5 Pro 화각 → 기본값 순으로 정한다.
```
python scripts\14_synthetic_demo.py --out outputs\synthetic                        # 기본으로 data/andriolo2024 사진 리포트도 함께
python scripts\13_estimate_mass.py --dsm ... --ortho ... --weights best.pt --photos DJI사진폴더   # EXIF 고도로 GSD 자동
```

## 만드는 법
```
python scripts\14_synthetic_demo.py --out outputs\synthetic   → outputs\synthetic\report.html
python scripts\13_estimate_mass.py --dsm ... --ortho ... --weights best.pt → outputs\mass\report.html
```
