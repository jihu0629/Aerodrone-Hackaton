# 결과 리포트 시각화 (report.html)

파이프라인이 결과를 낼 때마다 `report.html` 한 장을 만든다. 인터넷·추가 설치 없이 브라우저로 열린다.
미리보기(합성 장면): https://claude.ai/artifact/2vsp1eFnjP7yy6NtsBqncT

## 구성
1. 추정 총 무게 (큰 숫자) + 최소–최대 범위
2. 타일: 검출 개수, 총 부피, 마대·톤백·트럭, 작업 인·시간, 23 kg 초과, (실측 있으면) 오차
3. 검출 오버레이: 정사영상 위 종류별 색 윤곽, 마우스 올리면 종류·무게 범위·부피·면적·높이·계산 방식
4. 종류별 무게 막대 (대표값 + 범위 선)
5. 격자 무게 히트맵 (10 m, 우선 수거 순위 배지 1–5)
6. 기존 방식 비교: 우리 3D vs W2·W3·W3′ (실측 있으면 세로선)
7. 수거 계획 표, 무거운 물체 목록, 차량 경로
8. 전체 물체 표 (접힘)
9. 가정과 한계

## 설계 원칙
- 무게(크기)는 파란색 한 가지의 진하기, 종류는 고정 순서 8색 (색맹 검증 통과 팔레트)
- 모든 차트에 "표로 보기" 제공 (색 없이도 읽힘)
- 다크 모드·휴대폰 폭 대응
- 발표 화면은 브라우저에서 캡처
