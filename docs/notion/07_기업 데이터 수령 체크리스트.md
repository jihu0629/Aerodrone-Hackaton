# 기업 데이터 수령 체크리스트 (2026-10-01)

⭐ = 파이프라인 성립 여부를 가르는 항목. 받은 날 바로 확인하고 모르는 건 기업에 질문.

## ① 영상 형태
- [ ] ⭐ 연속 영상·겹치는 연속 사진인가, 서로 다른 장소의 낱장인가? (낱장이면 SfM 불가 → VGGT/단안 깊이로 전환)
- [ ] ⭐ 같은 장소를 여러 각도에서 찍었나?
- [ ] 정사영상·DSM·점군이 이미 들어 있나?
- [ ] 해상도·고도로 GSD 계산 (0.4–0.5 cm/px 면 부피 측정 가능)

## ② 스케일
- [ ] ⭐ EXIF 에 GPS·고도·초점거리가 있나? (`exiftool` 로 확인)
- [ ] GCP 나 RTK 가 있나?
- [ ] 드론·카메라 기종은?

## ③ 라벨
- [ ] ⭐ 박스(bbox)인가, 폴리곤·마스크인가? (박스만이면 SAM 으로 마스크 생성)
- [ ] 클래스가 재질·종류별로 나뉘어 있나? 클래스 목록
- [ ] 포맷 (COCO / YOLO / AI Hub JSON / LabelMe / VOC) — 노트북 ④ 가 자동 판별
- [ ] 클래스별 개수
- [ ] 라벨이 원본 프레임에 붙어 있나, 정사영상에 붙어 있나?

## ④ 정답
- [ ] ⭐ 실측 무게·크기·부피가 있나?
- [ ] 수거 기록(kg, 마대 수)이 있나? (수거 계획의 가정값을 실제값으로 교체 가능)

## ⑤ 조건
- [ ] 외부 데이터·사전학습 모델 사용 가능?
- [ ] 평가 기준?

## 공유할 것 (기술 파트너에게)
1. 노트북 ④ 셀 출력 (형식, 이미지 수, 라벨 샘플)
2. 노트북 ⑤ report 출력 (원본 클래스명별 개수, 매핑 결과)
3. .SRT 파일이 있으면 앞부분 10줄
4. 오류 메시지 전문
