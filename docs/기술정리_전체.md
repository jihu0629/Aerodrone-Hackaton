## 2. 파이프라인 단계별 기술

```
영상(.MP4) + 비행기록(.SRT: GPS·고도)
 ① 탐지 ──→ ② 3D 복원 ──→ ③ 위치(지도) ──→ ④ 부피 ──→ ⑤ 무게 ──→ ⑥ 수거계획 ──→ ⑦ 작업카드
 YOLO       SfM+MVS       광선-지면 교차    SAM2+높이지도   밀도×구간     클러스터+2-opt    HTML/지도
```

### ① 쓰레기 탐지 — `seg.py`, `video_map.py`, `orbit_map.py`
- **기술**: Ultralytics **YOLO11-s** (COCO 사전학습 → 우리 데이터로 미세조정). 4K 프레임은 **타일**(1024, 겹침 0.2)로 나눠 추론 후 병합(작은 물체 대응). 영상은 0.5~1초마다 한 프레임.
- **학습 데이터**
  - **AI Hub "해안 오염물질" (한국)**: 42만 장 중 1.2만 장을 골라 **고도별 GSD(2~4 cm/px)로 축소해 1024 판에 모자이크**(`aihub.py pack`) — 실제 드론 운용 고도의 물체 크기에 맞춤. 8클래스(스티로폼 부표/조각, 플라스틱 부표/기타, 페트병, 어망, 로프, 금속, 유리). **12 에폭 중 5**까지 학습.
  - **UAVVaste** (폴란드 도시, 772장): 범용 백업.
  - **하와이 칩 1,167장**: 단일 클래스 10분 미세조정(해외 적용 실험).
- **개방형 탐지 YOLO-World v2-s**: 클래스 이름을 **글로 지정**(`--classes "cardboard box"`). 야간 10분 영상에서 학습 모델 4개 → 상자 30개. 단, 범용 쓰레기(항공 시점 작은 물체)엔 거의 0 → "현장에서 새 종류 이름만 추가" 용도.
- **장애물**: COCO YOLO11-s로 사람·차량·오토바이 같이 지도화(수거 작업 안전).
- **중복 제거**: 지면 좌표에서 반경 병합(0.5~3.5 m) + 최소 관측 프레임 수.

### ② 3D 복원 — `orbit3d.py` + COLMAP
- **프레임 선택**: 구간(`--start/--end`)에서 n장, 블러(라플라시안 분산) 낮은 프레임 제외, 긴 변 1600 px로 축소.
- **SfM(뼈대)**: **pycolmap** — SIFT(최대 8192 특징) → **순차 매칭**(overlap 15, 영상용) 또는 전수 매칭(왕복 비행) → 증분 번들조정. CPU.
- **MVS(조밀)**: **COLMAP PatchMatch Stereo**(GPU) + stereo fusion. 기본값 45분 → **빠른 설정 3분 24초**(1200 px, 참고 8장, 반복 3, 샘플 10, window_step 2, 기하 일관성 유지, **cache 8 GB** — 기본 32 GB가 RAM 16 GB에서 스왑 → 노트북 꺼짐 원인).
- **실제 크기(축척)** — `volume.py to_metric_auto`: 기본은 카메라 높이 ↔ SRT 상대고도. 수평 이동이 크면 **3D 카메라 경로 ↔ GPS 경로**로 축척(SRT 고도가 이륙점 기준이라 틀릴 때, 0010 잔차 8.07 → 0.51 m). 0015는 고도가 1/5로 기록돼 `--min-track 4`로 강제.
- **바닥면**: RANSAC 평면.

### ③ 위치·지도 — `orbit_map.py`, `mosaic.py`, `video_map.py`
- 3D 카메라 자세로 **탐지 박스 → 광선 → 지면 교차** → 지면 좌표 → GPS 정렬(0007 잔차 1.16 m). 3D 없이 SRT만 쓰는 경량판(`video_map`)은 기수 방향을 이동 방향으로 추정(정확도 낮음).
- `mosaic.py`: 3D로 **정사영상(모자이크)** 생성 + 물체 표시 (1 cm/px).
- 출력: Leaflet 지도(`map.html`, 위성 타일, 썸네일 팝업), `objects.csv/geojson`.

### ④ 부피 — `objvol.py` (v2) ← **핵심 차별점**
1. 물체 중심 반경 안의 조밀 점을 후보로.
2. **SAM 2.1-base**로 프레임 24장에서 물체 마스크(점 프롬프트) → 각 3D 점이 마스크 안에 들어오는 비율로 **투표**(≥70 %)해 물체 점만 남김.
3. **지역 바닥 평면**(링 점 RANSAC) 기준 높이 → 바닥점(<3 cm) 제거 → 윗면 높이 = 높이 히스토그램 상단 봉우리(모서리 잡음·바닥 혼입 모두 완화).
4. **높이지도 부피**(격자별 높이 합) — 볼록껍질은 +60 % 과대라 폐기. 마스크 면적×높이는 수직 프레임 있을 때만.
5. 뒤집힌 카메라 포즈(제자리 회전 구간, 평면 장면 거울 반전) 자동 제외, 물체 중심 재추정(위치 오차 0.3~0.8 m 흡수).
- 결과: 0010 키 큰 상자 **높이 2 cm(실패) → 38 cm, 47.2 L(−10 %)**; 0007 38.8 L(+20 %), 3.7 L(+19 %).

### ⑤ 무게 — `weight.py`, `config.py`
- **물리식**: 부피 × 재질별 **겉보기 밀도**(스티로폼 20~25, 플라스틱 60, 어망·로프 100~400 kg/m³ 등) + **젖음 계수**(어망 2.0, 로프 1.8) + **마대 압축비**(EPS 10, 어망 2.5, PET 4) — 값은 가정이며 주석 표기.
- **학습식**(실측 라벨 30개 이상일 때): HistGradientBoosting + **split-conformal** 예측구간(log 공간). 지금은 실측이 없어 구간은 ×/÷2.
- **1인 들기 한계 23 kg**(NIOSH) 넘으면 2인/장비.
- **2D 전용(높이 없는 데이터)**: 면적 × 재질별 두께 범위 → 구간 (하와이, 업체 라벨 비교).

### ⑥ 수거계획 — `plan.py`
- 반경 기반 **클러스터**(정거장) → 정거장별 인력(1인/2인/장비)·마대(압축 후 부피·무게)·트럭(1 t) → 집하장 출발 **최근접 이웃 + 2-opt** 순회 경로.

### ⑦ 작업카드·보고 — `report.py`, `fromvideo.py`
- 정거장별 HTML 카드(썸네일·위경도·추정/최대 kg·인력·휴대폰 길찾기), 지도 그림, CSV/GeoJSON. `fromvideo.py`가 ④→⑦을 한 명령으로 연결 + 업체 방식 비교 그림.

### 가상비행 시뮬 — `sim_ortho.py`
- 업체 **문갑도 정사영상(3 cm/px)을 가상 세계**로: 고도·화각으로 카메라 시야를 잘라 리샘플(GSD 변화, 블러·노출·기수 잡음), 바람·돌풍·GPS 잡음.
- **지그재그 커버리지** 경로 → 프레임마다 YOLO(CPU) → 지도 투영·클러스터링(후보/확정/기각) → **능동 재방문**: 애매한 후보(0.25~0.5)는 8 m로 내려가 3장 재촬영 후 확정/기각. 재현율 0.71 → 0.86(라벨 7개 기준).
- 월드·카메라·비행·탐지·지도·계획 클래스 분리 → ROS 2/Gazebo(PX4 SITL, `do_orbit`)로 이식 설계.

### 데이터 처리 — `aihub.py`, `ortho.py`, `hawaii.py`, `crosseval.py`
- AI Hub tar에서 이미지 추출(받는 중에도) · LabelMe→COCO · GSD 축소 모자이크.
- 업체 ECW → QGIS GDAL로 GeoTIFF(2.3 GB) → 칩/정사영상 월드.
- 하와이 `.aux.xml`(GDAL PAM) 지오참조 파싱 → UTM 4N/5N → 위경도.
- 교차평가(클래스 무시, IoU 0.3).

## 3. 다른 접근과 다른 점 (특이점)

1. **"면적 × 계수"를 "3D 부피 × 밀도"로** — 업체 라벨 42개 합계 1.3 kg vs 현실 115~1,355 kg. 상자로 1/112·1/180 입증.
2. **SAM 2 마스크 투표로 점구름에서 물체만 분리** — 보통은 DSM 차분(기준 DSM 필요)이나 박스 안 점 전체를 씀. 우리는 여러 프레임 마스크의 일치율로 점을 고르고, 지역 평면·뒤집힌 포즈 제외까지 자동.
3. **영상 한 개로 끝까지** — 정사영상·DSM을 따로 만들지 않고 영상+SRT만으로 탐지→3D→위치→부피→작업카드.
4. **축척 자동 선택**(SRT 고도 vs GPS 경로) — SRT 고도가 틀린 실제 사례 두 번(0010, 0015) 모두 복구.
5. **조밀 복원 45분 → 3분** + 메모리 상한(노트북 8 GB GPU·16 GB RAM에서 안정).
6. **운용 고도 GSD에 맞춘 학습셋**(AI Hub 고해상도 사진을 2~4 cm/px로 축소 모자이크) → 문갑도 재현율 0.72(UAVVaste 0.28).
7. **"한 번 만든 모델이 다른 해안에서도"** — 하와이 0.24 → 10분 미세조정 0.58, 니하우 섬 수거계획까지.
8. **개방형 탐지로 새 종류 즉시 추가** (야간 상자 30개), 범위와 한계(항공 작은 물체엔 무력)를 측정해 제시.
9. **실기체 없이도 운용 알고리즘 검증** — 정사영상 가상비행 + 능동 재방문 효과 수치화.
10. **솔직한 한계 보고**: 작은 상자 −3 %는 운이었음(v2 +19 %), 0015 부피 실패 원인(단방향 경사·연석·어두운 바닥) → 촬영 가이드로 연결.
